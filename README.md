# My_Library_Journey

Unveiling the evolutionary journey in Java's language, implementing a Java backend library project: A progressive deep dive into database persistence. Each branch meticulously develops core technologies, from foundational JDBC to sophisticated JPA and Hibernate, showcasing robust data manipulation across the rich Java ecosystem.

---

## Plan

Project divided in 4 Steps

1. Level 1:
   - Just JDBC;
   - Entities: Book, Author and Publisher;
   - Design Patterns;
   - Maven;
   - PostgreSQL;
   - Generics;
2. Continue...
